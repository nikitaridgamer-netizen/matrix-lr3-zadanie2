# НАЗВАНИЕ ПРОЕКТА

Программа удаления заданного столбца из вещественной матрицы

## КРАТКОЕ НАЗНАЧЕНИЕ

Программа предназначена для обработки вещественных (дробных) матриц размерности n × m.

Основная функция — удаление столбца с номером k, который выбирает пользователь.

Проект реализован с использованием клиент-серверной архитектуры: данные вводятся в клиенте, передаются по протоколу REST API (JSON) на сервер, где происходит обработка (удаление столбца), после чего результат возвращается обратно клиенту.

## ТРЕБОВАНИЯ К ОКРУЖЕНИЮ

- Язык программирования: Python 3.x
- Операционная система: любая (Windows, Linux, macOS), поддерживающая Python
- Дополнительные библиотеки: fastapi, uvicorn, requests
- Оборудование: любой компьютер, на котором установлен интерпретатор Python

## ИНСТРУКЦИИ ПО ЗАПУСКУ

1. Установите Python 3.x, если он ещё не установлен.
2. Установите необходимые библиотеки. Откройте терминал и выполните команду:

pip install fastapi uvicorn requests

3. Запустите сервер (в первом окне терминала):

python src/server.py

4. Откройте второе окно терминала и запустите клиент:

python src/project.py

5. Следуйте инструкциям программы в окне клиента.
