# Сравнительный анализ стратегий интеграции

В ходе проектирования были рассмотрены следующие стратегии:

1. **Нисходящая:** Начинается с главного модуля. Плюсы: раннее выявление ошибок в архитектуре. Минусы: требуются заглушки.
2. **Восходящая:** Начинается с нижних модулей. Плюсы: не нужны заглушки, тестируется реальный код. Минусы: главный модуль тестируется в последнюю очередь.
3. **Сэндвич:** Комбинация первых двух. Применяется для очень крупных систем.
