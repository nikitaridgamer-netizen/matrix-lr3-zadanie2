# Результаты тестирования интеграции

## Составленные тестовые сценарии

В ходе тестирования интеграции клиент-серверного приложения были проверены следующие сценарии:

### 1. Успешное взаимодействие
- **Действие:** Пользователь в клиенте вводит матрицу размерностью 3x3 и указывает номер столбца для удаления. Клиент отправляет POST-запрос на сервер.
- **Результат:** Сервер принимает JSON, выполняет удаление столбца, возвращает статус `200 OK` и JSON с новой матрицей. Клиент корректно выводит результат.

### 2. Обработка исключительной ситуации: недоступность cервера
- **Действие:** Пользователь запускает только клиент (`project.py`), сервер (`server.py`) выключен.
- **Результат:** Выведено сообщение «Подключение не установлено, т.к. конечный компьютер отверг запрос на подключение».

### 3. Обработка некорректных данных (Валидация на клиенте)
- **Действие:** Пользователь пытается ввести несуществующий номер столбца.
- **Результат:** Сработала проверка в `input_project.py` (`while k < 1 or k > m`). Отправка запроса на сервер не произошла.

## Вывод по тестированию
Все тестовые сценарии пройдены успешно. Организованное взаимодействие модулей через REST API стабильно. Обработка исключительных ситуаций, таких как недоступность сервера и некорректный ввод, работает корректно. Выявленных ошибок интеграции не обнаружено.
